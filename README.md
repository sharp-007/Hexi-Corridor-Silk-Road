## 项目简介

河西走廊，东起乌鞘岭、西至玉门关，绵延近 1000 公里，夹于祁连山脉与腾格里沙漠、巴丹吉林沙漠之间。两千多年来，它是中原通往西域的咽喉要道，是丝绸之路的黄金段，承载着无数商旅、使团、僧侣与戍卒的足迹。

本项目通过 **JMP** 软件创建交互式数据可视化 Journal，从地理、历史、文化、气候等多维度探索河西走廊，将数据分析与旅行攻略融为一体，让数据讲述这条千年古道的故事。

## 打开方式

1. 安装 [JMP](https://www.jmp.com/) 统计分析软件（需 JMP 19 版本）
2. 克隆或下载本仓库
3. 双击 `.jrn` 文件，即可在 JMP 中打开交互式 Journal查看旅行路线


## 关于 JMP

[JMP](https://www.jmp.com/) 是 SAS 旗下的交互式统计分析与数据可视化软件，以其强大的图形化探索能力著称。JMP Journal (`.jrn`) 是一种交互式报告格式，可嵌入图表、数据表、分析结果和脚本，便于分享和展示数据故事。
